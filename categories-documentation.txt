# Categories Page - Complete Technical Documentation
# Ice-Center E-commerce Platform
# ================================================

## Overview

The Categories system consists of two main pages:
1. **Categories Index Page** (`/categories`) - Shows all categories with products
2. **Category Detail Page** (`/categories/[slug]`) - Shows products for a specific category

Both pages use Server-Side Rendering (SSR) with Next.js App Router and share similar filtering/sorting logic.

---

```
src/app/(shop)/categories/
```

## 3. DATABASE SCHEMA (Prisma)

```prisma
model Category {
  id          Int           @id @default(autoincrement())
  name        String
  slug        String        @unique
  description String?
  image       String?
  subcategories Subcategory[]
}

model Subcategory {
  id          Int       @id @default(autoincrement())
  name        String
  slug        String
  categoryId  Int
  category    Category  @relation(fields: [categoryId], references: [id])
  products    Product[]
}

model Product {
  id             Int       @id @default(autoincrement())
  name           String
  slug           String    @unique
  price          Float
  listPrice      Float?    // Original price (for discount calc)
  thumbnail      String?
  isActive       Boolean   @default(true)
  inventoryStatus String   // IN_STOCK, LOW_STOCK, OUT_OF_STOCK
  brand          String?
  subcategoryId  Int
  subcategory    Subcategory @relation(fields: [subcategoryId], references: [id])
  createdAt      DateTime  @default(now())
}
```

```typescript
// Products where listPrice > price
if (onlyDiscount) {
  allProducts = allProducts.filter(p => p.listPrice && p.listPrice > p.price);

// Discount percentage calculation:
const getDiscount = (price, listPrice) => {
  if (!listPrice || listPrice <= price) return null;
  return Math.round(((listPrice - price) / listPrice) * 100);
};
```

## 8. URL QUERY PARAMETERS

| Param        | Type     | Example                    | Description           |
|--------------|----------|----------------------------|-----------------------|
| page         | number   | ?page=2                    | Pagination            |
| sort         | string   | ?sort=price-asc            | Sort order            |
| category     | number   | ?category=5                | Filter by category    |
| subcategory  | number   | ?subcategory=12            | Filter by subcategory |
| minPrice     | number   | ?minPrice=1000000          | Min price filter      |
| maxPrice     | number   | ?maxPrice=5000000          | Max price filter      |
| brands       | string   | ?brands=Samsung,LG         | Brand filter (CSV)    |
| availability | string   | ?availability=IN_STOCK     | Stock status (CSV)    |
| discount     | boolean  | ?discount=true             | Only discounted       |

## 9. PERFORMANCE OPTIMIZATIONS

1. **Server-Side Rendering** - Data fetched on server, faster initial load
2. **Revalidation** - `export const revalidate = 300` (5 minutes cache)
3. **Prisma Queries** - Optimized with `select` to fetch only needed fields
4. **Image Optimization** - Next.js Image component with lazy loading
5. **URL-based State** - No client-side API calls for filtering

## 10. KEY DEPENDENCIES

- **Next.js 16** - React framework with App Router
- **Prisma** - ORM for database queries

## 11. RTL SUPPORT

- All layouts use `dir="rtl"`
- Embla Carousel configured with `direction: 'rtl'`
- Tailwind utilities for RTL (gap-x instead of margin, etc.)
- Persian number formatting using `Intl.NumberFormat('fa-IR')`

---

## 12. ERROR HANDLING

- 404 page if category not found: `if (!category) notFound();`
- Empty state UI when no products match filters
- Database connection errors handled by Next.js error boundary
