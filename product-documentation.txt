# Product Page - Complete Technical Documentation
# Ice-Center E-commerce Platform
# ================================================

## Overview

The Product Page displays individual product details at `/products/[slug]`.
It uses Server-Side Rendering (SSR) with Next.js App Router for SEO and fast loading.

## 1. SERVER COMPONENT (page.tsx)

### Location: `/src/app/(shop)/products/[slug]/page.tsx`

### Main Function: `getProductBySlug`

```typescript
async function getProductBySlug(slug: string) {
    const product = await prisma.product.findUnique({
        where: { slug },
        include: {
            subcategory: {
                include: {
                    category: true
                }
            }
        }
    });
    return product;
}
```

### Data Flow:

1. **Extract slug** from URL params
2. **Fetch product** from database with subcategory and category relations
3. **Return 404** if product not found: `notFound()`
4. **Build specifications** from database fields:
   - Technical specs (brand, model, country, condition)
   - Electrical specs (voltage, phase, power, cooling)
   - Dimension specs (width, depth, height, weight)
   - Additional specs from JSON field
5. **Transform data** for client component
6. **Render ProductClient** with transformed data

### Specifications Builder Algorithm:

```typescript
// Technical specs
if (product.brand) technicalSpecs.push({ label: 'برند', value: product.brand });
if (product.model) technicalSpecs.push({ label: 'مدل', value: product.model });
if (product.manufacturingCountry) technicalSpecs.push({ label: 'کشور سازنده', value: product.manufacturingCountry });

// Electrical specs
if (product.voltage) electricalSpecs.push({ label: 'ولتاژ', value: product.voltage });
if (product.phase) electricalSpecs.push({ label: 'فاز', value: `${product.phase} فاز` });
if (product.power) electricalSpecs.push({ label: 'توان', value: product.power });

// Dimension specs
if (product.width) dimensionSpecs.push({ label: 'عرض', value: `${product.width} سانتی‌متر` });
if (product.depth) dimensionSpecs.push({ label: 'عمق', value: `${product.depth} سانتی‌متر` });
if (product.height) dimensionSpecs.push({ label: 'ارتفاع', value: `${product.height} سانتی‌متر` });

// Group into categories
if (technicalSpecs.length > 0) specifications.push({ title: 'مشخصات فنی', specs: technicalSpecs });
if (electricalSpecs.length > 0) specifications.push({ title: 'مشخصات الکتریکی', specs: electricalSpecs });
if (dimensionSpecs.length > 0) specifications.push({ title: 'ابعاد و وزن', specs: dimensionSpecs });
```

## 4. DATABASE SCHEMA (Product Model)

```prisma
model Product {
  id                  Int       @id @default(autoincrement())
  name                String
  slug                String    @unique
  sku                 String?
  price               Float
  listPrice           Float?    // Original price for discount
  stock               Int       @default(0)
  inventoryStatus     String    @default("IN_STOCK") // IN_STOCK, LOW_STOCK, OUT_OF_STOCK
  isActive            Boolean   @default(true)
  
  // Media
  thumbnail           String?
  images              String[]  // Array of image URLs
  
  // Content
  description         String?   @db.Text
  features            String[]  // Array of feature strings
  specifications      Json?     // Additional specs as JSON
  
  // Technical
  brand               String?
  model               String?
  manufacturingCountry String?
  condition           String?   // NEW, REFURBISHED, USED
  
  // Electrical
  powerSource         String?   // ELECTRIC, GAS, HYBRID
  voltage             String?
  phase               Int?
  power               String?
  powerConsumption    Float?
  coolingSystem       String?   // AIR, WATER, HYBRID
  
  // Dimensions
  width               Float?
  depth               Float?
  height              Float?
  weightNet           Float?
  weightGross         Float?
  
  // Commerce
  warranty            String?
  rating              Float?    @default(0)
  reviewCount         Int       @default(0)
  
  // Relations
  subcategoryId       Int
  subcategory         Subcategory @relation(fields: [subcategoryId], references: [id])
  
  // Timestamps
  createdAt           DateTime  @default(now())
  updatedAt           DateTime  @updatedAt
}
```
